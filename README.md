# Трекер расходов

Минималистичное Flutter-приложение для учёта расходов на Android.

## Возможности

- Главный экран со списком расходов (категория, сумма, дата, заметка) и карточкой сумм за сегодня и за месяц
- Добавление расхода через bottom sheet: сумма, категория (Еда, Транспорт, Жильё, Развлечения, Здоровье, Покупки, Другое), заметка, дата
- Свайп для удаления расхода (с возможностью отменить)
- Локальное хранение данных через `shared_preferences`, без бэкенда
- Material 3, тёмный акцентный цвет `#2D2D2D`

## Запуск

```bash
flutter pub get
flutter run
```

## Сборка APK

```bash
flutter build apk --release
```

APK также автоматически собирается в GitHub Actions при каждом push в `main` и доступен как artifact сборки (см. вкладку Actions).
