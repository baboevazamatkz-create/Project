# Сканер, советы и голосовой помощник: серверный посредник

Приложение не может обращаться к ИИ напрямую: ключ пришлось бы положить
внутрь сборки, а веб-сборка и APK разбираются кем угодно. Поэтому между
ними стоит воркер Cloudflare — он хранит ключ у себя, проверяет, что
запрос пришёл из приложения, и возвращает уже разобранные операции.

Один воркер отвечает за три раздела приложения — все под тем же адресом,
с той же проверкой входа и тем же суточным лимитом:

- `/` (сканер чеков) — распознаёт снимки чеков и выписок.
- `/advice` (советы по расходам) — разбирает суммы по категориям за
  текущий и прошлый месяц и предлагает, на чём можно сэкономить.
- `/voice` (голосовой помощник) — разбирает надиктованную и распознанную в
  текст фразу: понимает, что это — новая запись или вопрос о тратах — и
  извлекает из неё параметры.

Отдельно разворачивать `/advice` или `/voice` не нужно: оба уже есть в
`worker/src/index.js`, и шаги ниже разворачивают все три раздела разом.

Бесплатного тарифа Cloudflare (100 000 запросов в сутки) хватает с
избытком; платить нужно только за сами обращения к модели.

## Что понадобится

1. Аккаунт Cloudflare — https://dash.cloudflare.com/sign-up
2. Ключ Anthropic API — https://console.anthropic.com → API Keys
3. Node.js на компьютере (для `npx`)

## Развёртывание

```bash
cd worker

# 1. Вход в Cloudflare (откроется браузер)
npx wrangler login

# 2. Ключ к модели. Команда спросит его и сохранит на стороне Cloudflare;
#    в репозиторий ключ не попадает.
npx wrangler secret put ANTHROPIC_API_KEY

# 3. Публикация
npx wrangler deploy
```

Последняя команда напечатает адрес вида

```
https://solidus-scan.<ваше-имя>.workers.dev
```

Это и есть адрес сканера.

## Если Node.js на компьютере нет

То же самое делается прямо в браузере:

1. https://dash.cloudflare.com → **Workers & Pages** → **Create** →
   **Start with Hello World!** → **Deploy**
2. **Edit code** → выделить всё в редакторе и вставить содержимое
   `worker/src/index.js` из этого репозитория → **Deploy**
3. **Settings** → **Variables and Secrets**:
   - *Secret*: `ANTHROPIC_API_KEY` — ключ из консоли Anthropic
   - *Text*: `FIREBASE_PROJECT_ID` = `money-78d6d`
   - *Text*: `MODEL` = `claude-haiku-4-5-20251001`
   - *Text*: `DAILY_LIMIT` = `60`

   Этот шаг обязателен: при публикации из браузера `wrangler.toml` не
   читается, и переменные оттуда сами не появятся.
4. Адрес воркера написан на его странице, в разделе **Domains & Routes**.

## Подключение к приложению

Адрес не секретный, но в коде его нет — он приходит при сборке. Заведите
переменную репозитория:

**GitHub → Settings → Secrets and variables → Actions → Variables → New
repository variable**

- Name: `SCAN_ENDPOINT`
- Value: адрес из предыдущего шага

После этого любая следующая сборка (веб и APK) увидит сканер. Пока
переменная не задана, кнопка сканера в приложении просто не показывается —
всё остальное работает как раньше.

Для локальной сборки то же самое делается флагом:

```bash
flutter run --dart-define=SCAN_ENDPOINT=https://solidus-scan.<имя>.workers.dev
```

## Ограничение числа разборов (необязательно, но стоит)

Вход в приложение анонимный, то есть токен может получить кто угодно.
Счётчик не даёт одному пользователю разобрать больше `DAILY_LIMIT`
снимков в сутки:

```bash
npx wrangler kv namespace create SCAN_QUOTA
```

Команда выдаст `id`. Раскомментируйте в `wrangler.toml` блок
`[[kv_namespaces]]`, подставьте этот `id` и выполните `npx wrangler deploy`
ещё раз. Без этого блока воркер работает, но без ограничения.

## Обновление воркера

Код воркера иногда меняется вместе с приложением. Тогда его нужно
опубликовать заново — приложение пересобирать не обязательно:

- через wrangler: `git pull`, затем `cd worker && npx wrangler deploy`.
  Без `git pull` wrangler опубликует тот код, что лежит в вашей локальной
  папке, — то есть старый.
- через браузер: страница воркера → **Edit code** → выделить всё,
  вставить свежий `worker/src/index.js` → **Deploy**. Если файл скачан
  не в первый раз, телефон или браузер сохранит новый как
  `index (1).js`, а старый `index.js` останется рядом — вставлять нужно
  именно свежий. Проверить просто: в редакторе поиском должно находиться
  `WORKER_VERSION`.

Ключ и переменные при этом сохраняются, заново их вводить не нужно.

**После публикации обязательно проверьте**, что опубликовалось то, что
нужно: откройте адрес воркера в браузере. Должно быть написано

```
solidus-scan ok
версия 3: сканер (/), советы (/advice), голос (/voice)
```

Если видна только первая строка `solidus-scan ok` — на Cloudflare всё ещё
старый код, и голосовой помощник работает в упрощённом режиме (понимает
простые фразы вроде «потратил 500 на такси» на самом телефоне, без ИИ).

## Проверка

```bash
curl https://solidus-scan.<имя>.workers.dev
# solidus-scan ok
# версия 3: сканер (/), советы (/advice), голос (/voice)

curl -X POST https://solidus-scan.<имя>.workers.dev -d '{}'
# {"error":"Нужен вход в приложение"}
```

Второй ответ — это правильно: без токена Firebase воркер ничего не делает.

## Сколько это стоит

Один чек — это примерно полторы тысячи входных токенов и сотня выходных.
На моделях класса Haiku это доли цента за снимок, то есть сотня чеков в
месяц обойдётся в несколько рублей. Списывается с баланса Anthropic;
Cloudflare в этих объёмах бесплатен.

## Что воркер отдаёт

```json
{
  "document": "receipt | statement | other",
  "transactions": [
    {
      "type": "expense | income",
      "amount": 1234.5,
      "currency": "rub | kzt | usd",
      "date": "2026-09-13",
      "note": "Магнит",
      "category": "food | transport | housing | entertainment | health | shopping | other",
      "confidence": 0.92
    }
  ]
}
```

Ответ проверяется и подрезается на стороне воркера: отрицательные суммы,
неизвестные категории и мусорные даты до приложения не доходят. Разбор
этого ответа со стороны приложения закреплён тестами в
`test/scan_test.dart`.

## Что отдаёт `/advice`

Приложение отправляет туда не сами записи, а уже посчитанные суммы: по
категориям за этот и прошлый месяц, итоги дохода и расхода, заданные
лимиты. Ни текста заметок, ни названий магазинов воркер не видит —
только цифры, которых достаточно, чтобы сказать «слишком много на такси».

```json
{
  "verdict": "positive | neutral | concerning",
  "headline": "Одно предложение о месяце в целом",
  "tips": [
    {
      "category": "food | transport | housing | entertainment | health | shopping | other | general",
      "severity": "info | warning",
      "title": "Коротко, о чём совет",
      "detail": "Что конкретно сделать"
    }
  ]
}
```

При записей меньше трёх за оба месяца воркер отвечает ошибкой
(«Пока маловато записей для разбора») вместо того, чтобы придумывать
анализ на пустом месте. Разбор ответа и сборка запроса закреплены
тестами в `test/advice_test.dart`.

## Что отдаёт `/voice`

Приложение отправляет туда только саму фразу (уже распознанный речью
текст) и сегодняшнюю дату — никаких сумм, записей или истории трат. Всё,
что нужно этому маршруту, — понять намерение и вытащить из фразы
параметры; сами расчёты («сколько потрачено») приложение делает на
устройстве из уже загруженных записей, так что воркер их вообще не
видит.

```json
{
  "intent": "add | query | unclear",
  "type": "expense | income | net",
  "amount": 500,
  "category": "food | transport | housing | entertainment | health | shopping | other | all",
  "date": "2026-09-28",
  "period": "today | yesterday | this_week | this_month | last_month | all",
  "note": "такси"
}
```

Какие поля значимы, зависит от `intent`: `add` — это `type`, `amount`,
`category`, `date`, `note`; `query` — это `type`, `category`, `period`;
`unclear` — фраза не про деньги или бессмысленная, остальные поля не
важны. Разбор ответа и локальный подсчёт закреплены тестами в
`test/voice_test.dart`.

Если воркер недоступен, исчерпал суточный лимит или ещё не обновлён до
версии с `/voice`, приложение разбирает фразу само, на телефоне
(`lib/models/voice_parser.dart`): простые команды и вопросы понимает и
без сервера, а сервер нужен для свободной речи. Старый воркер без
`/voice` приложение узнаёт по отсутствию заголовка `X-Solidus-Worker`
в ответе и в этом случае не показывает его бессмысленное «Пустой
снимок».
