# Карточка приложения в Google Play (русский)

Всё, что ниже, вставляется в **Play Console → Основная информация о
приложении**. Ограничения по длине — от Google; в скобках указано, сколько
занято сейчас.

## Название (до 30 символов)

```
Solidus — общий бюджет
```

## Краткое описание (до 80 символов)

Показывается в списках и в поиске. Первое, что читают.

```
Общий бюджет на двоих: расходы, доходы и сканер чеков с ИИ
```

## Полное описание (до 4000 символов)

```
Solidus — приложение для тех, кто ведёт деньги вдвоём.

Один код — один общий бюджет. Второй участник вводит его у себя, и с этой
минуты вы видите одни и те же записи: добавили трату — она появилась у
обоих.

СКАНЕР ЧЕКОВ И ВЫПИСОК
Сфотографируйте чек или выберите скриншот из банковского приложения — ИИ
прочитает суммы, даты и названия продавцов и сам разложит их по категориям.
Чек превращается в одну запись с итогом, выписка — в список операций,
строку за строкой. Перед записью всё видно: лишнее снимается галочкой,
ошибка исправляется на месте. В бюджет попадает только то, что вы
подтвердили.

ВИДЖЕТ НА ЭКРАНЕ ТЕЛЕФОНА
Клавиатура, выбор категории и две кнопки — расход и доход. Записывает
прямо в общий бюджет, приложение открывать не нужно. Размер задаётся
как у любого виджета.

ЧТО ЕЩЁ
• Расходы и доходы: сумма, категория, дата, заметка
• Семь категорий: еда, транспорт, жильё, развлечения, здоровье, покупки,
  другое
• Список подряд или траты месяца, собранные по категориям
• Статистика: круговая диаграмма, лимиты на каждую категорию и итоги за
  полгода
• Рубли, тенге и доллары; приблизительный пересчёт, чтобы взглянуть на
  бюджет в другой валюте
• Светлая и тёмная тема
• Несколько бюджетов сразу: семья, поездка, работа — переключение одним
  нажатием
• Свайп по записи удаляет её, с возможностью отменить

БЕЗ ЛИШНЕГО
Ни регистрации, ни телефона, ни почты, ни пароля — приложение открывается
сразу. Рекламы нет. Платных подписок нет. Аналитики и трекеров нет.

Solidus — единый ритм малых финансов.
```

## Что нового (до 500 символов, на каждый выпуск)

Для первой публикации:

```
Первая версия Solidus.

• Общий бюджет по коду: записи видны всем участникам сразу
• Сканер чеков и банковских выписок — распознаёт суммы, даты и категории
• Виджет на домашний экран: запись расхода без открытия приложения
• Статистика по категориям с лимитами
• Рубли, тенге и доллары
• Светлая и тёмная тема
```
