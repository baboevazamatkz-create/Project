# Ответы на анкеты Play Console

Три анкеты, без которых приложение не выйдет из черновика: **Безопасность
данных**, **Возрастной рейтинг** и **Контент приложения**. Ниже — что
отвечать и почему. Отвечать нужно честно: несовпадение анкеты с тем, что
приложение делает на самом деле, — самая частая причина снятия с публикации.

---

## 1. Безопасность данных (Data safety)

### Общие вопросы

| Вопрос | Ответ |
| --- | --- |
| Собирает ли приложение данные? | **Да** |
| Передаются ли данные по защищённому соединению? | **Да** (везде TLS) |
| Могут ли пользователи запросить удаление данных? | **Да** |
| Проходило ли приложение независимый аудит безопасности? | Нет |
| Соответствие политике Play для семей? | Не применяется (аудитория 18+) |

### Типы данных

Отмечать только эти три. Всё остальное — «не собирается».

**Личная информация → Идентификаторы пользователя**
- Собирается: да. Передаётся третьим лицам: нет.
- Обрабатывается только временно: нет.
- Обязательно для работы приложения.
- Цель: работа приложения.
- *Почему:* Firebase Authentication заводит анонимный идентификатор
  устройства. Ни имени, ни почты, ни телефона приложение не спрашивает, но
  сам идентификатор хранится.

**Финансовая информация → Другая финансовая информация**
- Собирается: да. Передаётся третьим лицам: нет.
- Обрабатывается только временно: нет.
- Обязательно для работы приложения.
- Цель: работа приложения.
- *Почему:* суммы, даты, категории и заметки записей хранятся в Firestore.

**Фото и видео → Фотографии**
- Собирается: да. Передаётся третьим лицам: нет.
- **Обрабатывается только временно: да.**
- Необязательно (пользователь выбирает сам).
- Цель: работа приложения.
- *Почему:* снимок чека уходит на распознавание и нигде не сохраняется —
  ни у нас, ни в журнале. Строго говоря, Google разрешает не указывать
  данные, которые обрабатываются только временно; указать их честнее и
  ничем не грозит.

### Про «передачу третьим лицам»

Google, Cloudflare и Anthropic — исполнители, обрабатывающие данные по
нашему поручению, а не получатели, распоряжающиеся ими самостоятельно. По
определению Play это **не** «передача данных третьим лицам». В политике
конфиденциальности они названы поимённо — этого достаточно.

## 2. Возрастной рейтинг (анкета IARC)

- Категория: **Служебное приложение, продуктивность, связь или другое**
- Насилие, кровь, страх — нет
- Сексуальный контент, нагота — нет
- Нецензурная лексика — нет
- Наркотики, алкоголь, табак — нет
- Азартные игры, симуляция азартных игр — нет
- Покупки за реальные деньги — нет
- Реклама — нет
- Определение местоположения и его передача — нет
- Обмен личной информацией между пользователями — нет
- **Пользовательский контент, видимый другим пользователям — да.**
  Участники одного бюджета видят заметки друг друга. Это не чат и не
  публикация: круг ограничен теми, кому вы сами дали код. Отвечать «нет»
  было бы неправдой — поле заметки свободное.

Ожидаемый рейтинг: для всех возрастов либо 3+.

## 3. Контент приложения (App content)

**Целевая аудитория**
- Возрастные группы: **18 лет и старше**.
  Приложение про личные деньги. Выбор 18+ снимает требования политики
  для семей, которые к такому приложению отношения не имеют.
- Привлекает ли приложение детей: нет.

**Политика конфиденциальности**
```
https://baboevazamatkz-create.github.io/Project/privacy.html
```

**Реклама**: приложение не содержит рекламы.

**Доступ к приложению**: вся функциональность доступна без ограничений —
ни логина, ни пароля, ни кода доступа для проверяющего не нужно.

**Финансовые функции**: *приложение не предоставляет финансовых функций.*
Это важно отметить правильно: Solidus ведёт учёт, но не выдаёт займов, не
проводит платежей, не работает с криптовалютой, не даёт инвестиционных
советов и не подключается к банковским счетам. Любой другой ответ включает
требование прислать лицензии.

**Удаление аккаунта**: приложение не предлагает создавать аккаунт —
вход анонимный, без регистрации. Способ удалить данные всё равно описан в
политике и есть внутри приложения (кнопка очистки бюджета и выход из
бюджета).

**Генеративный ИИ**: да, приложение использует ИИ — распознаёт содержимое
снимков, которые пользователь выбирает сам. Результат — не сгенерированный
текст или картинка, а суммы, даты и названия, которые пользователь
подтверждает перед записью. Адрес для обращений указан в политике. Если
Google дополнительно попросит встроенную кнопку «пожаловаться» — это
делается отдельным небольшим изменением.

**Здоровье, государственные приложения, новости, VPN, слежение** — ничего
из этого.

## Инструкция для проверяющего

Поле «Инструкции для проверки» в разделе «Доступ к приложению». Текст:

```
Регистрация не требуется. При первом запуске нажмите «Создать новый
бюджет», введите любое название и выберите валюту — приложение сразу
откроется.

Чтобы проверить сканер: кнопка со значком рамки и искры внизу экрана →
«Выбрать из галереи» → любой снимок чека. Распознанные строки появятся
в шторке, записывается только отмеченное.

Второй участник подключается по коду бюджета: список бюджетов в правом
верхнем углу → «⋮» → «Скопировать код».
```
